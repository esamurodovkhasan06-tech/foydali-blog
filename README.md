# Foydali Blog

Astro + TypeScript asosidagi oʻzbek tilidagi blog. Maqolalar `src/content/articles/` papkasida Markdown koʻrinishida.

    npm install
    npm run dev      # http://localhost:4321/foydali-blog/
    npm run build    # dist/ papkasiga tayyor sayt
    npm run preview  # tayyor saytni koʻrish

Joylashdan oldin `astro.config.mjs` (site, base) va `src/consts.ts` (email) ni oʻzgartiring.
